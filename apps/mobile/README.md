# Запуск BASE на телефоне через USB

Это не браузерная страница — Android Studio соберёт настоящий `.apk` и
установит его на телефон как обычное приложение. Иконка появится на
рабочем столе, открывается без адресной строки браузера.

## Один раз: подготовка

1. **Установи Android Studio** — https://developer.android.com/studio
   (macOS/Windows/Linux). Она сама подтянет Android SDK и нужный Java —
   это единственное, что реально нужно поставить, дальше всё через неё.

2. **Включи режим разработчика на телефоне:**
   - Настройки → О телефоне → 7 раз тапнуть по «Номер сборки»
   - Настройки → Для разработчиков → включить «Отладка по USB»

3. **Подключи телефон к компьютеру USB-кабелем.** На телефоне появится
   запрос «Разрешить отладку по USB?» — подтверди.

4. **Проверь, что телефон определился:**
   ```bash
   adb devices
   ```
   Должен показать твой телефон со статусом `device` (не `unauthorized`
   — если так, разблокируй телефон и подтверди запрос ещё раз).

   Если `adb` не найден — он ставится вместе с Android Studio, обычно
   тут: `~/Library/Android/sdk/platform-tools` (Mac) или
   `%LOCALAPPDATA%\Android\Sdk\platform-tools` (Windows). Добавь эту
   папку в PATH, либо просто открой Android Studio один раз — она
   предложит доустановить platform-tools сама.

## Каждый раз, когда хочешь запустить

1. **Запусти сам веб-редактор** (в корне репозитория):
   ```bash
   bun run dev:web
   ```
   Оставь это окно терминала открытым — сервер должен работать, пока
   пользуешься приложением на телефоне.

2. **Пробрось порт с телефона на компьютер через USB** (в новом окне
   терминала):
   ```bash
   adb reverse tcp:3000 tcp:3000
   ```
   Это позволяет телефону обращаться к `localhost:3000` так, будто
   сервер запущен прямо на нём — трафик идёт через USB-кабель, Wi-Fi не
   нужен.

3. **Собери и запусти на телефоне:**
   ```bash
   cd apps/mobile
   bun install
   npx cap sync android
   npx cap open android
   ```
   Откроется Android Studio с проектом. Сверху выбери своё устройство в
   выпадающем списке (рядом с зелёной кнопкой ▶️) и нажми **Run**.

   Первая сборка займёт пару минут (Gradle качает зависимости) — дальше
   быстрее. После сборки приложение само установится и откроется на
   телефоне.

## Если после установки на телефоне белый экран

Значит порт не пробросился или сервер не запущен — проверь:
- `bun run dev:web` всё ещё работает в терминале
- `adb reverse tcp:3000 tcp:3000` выполнен ПОСЛЕ подключения телефона
  (если переподключал кабель — выполни заново)
- на телефоне физически открой Chrome и зайди на `http://localhost:3000`
  — если там тоже белый экран, проблема в проксировании порта, а не в
  приложении

## Когда будешь готовы к реальному релизу

Сейчас `capacitor.config.ts` настроен на локальную разработку
(`http://localhost:3000`). Перед сборкой релизной версии для Google
Play — поменяй `server.url` на адрес задеплоенного сайта (например,
`https://your-app.vercel.app/studio`) и `cleartext: false`, иначе
собранное приложение будет пытаться достучаться до твоего компьютера,
а не до реального сервера.
